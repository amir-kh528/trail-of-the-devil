# Trail of the Devil

[**English**](README.md) | [**فارسی**](README.fa.md) | [**Русский**](README.ru.md)

Лёгкий проект на PHP для современной страницы бизнеса с формой обратной связи и административной панелью для управления входящими сообщениями.

## О проекте

Этот проект создан как простой, но профессиональный локальный веб-проект для digital-агентства или стартапа. В него входят адаптивная landing page, форма обратной связи, сохраняющая заявки в MySQL, и административная панель для просмотра, поиска, редактирования и удаления сообщений.

## Возможности

- Адаптивная landing page для digital-агентства или стартапа
- Форма обратной связи с валидацией и AJAX-ответом
- Хранение сообщений в MySQL
- Панель администратора для просмотра и фильтрации сообщений
- Управление статусом прочитано/не прочитано
- Массовое удаление и пометка сообщений
- RTL-структура для Persian с пользовательской типографикой и стилями

## Установка и настройка

1. Запустите Apache и MySQL через XAMPP.
2. Настройте переменные `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`, `ADMIN_USERNAME` и `ADMIN_PASSWORD_HASH` в окружении, доступном PHP. `.env.example` только документирует имена; приложение не загружает `.env`.
3. Создайте хеш пароля администратора локально через `password_hash($password, PASSWORD_DEFAULT)` и задайте в `ADMIN_PASSWORD_HASH` только хеш. Не добавляйте пароль или хеш в Git.
4. Перед миграцией существующей или рабочей базы создайте и проверьте резервную копию. Затем запустите миграции из корня проекта через CLI:
   - `php database/migrate.php`
   - Для `APP_ENV=production` после подтверждения проверенной копии используйте `php database/migrate.php --backup-confirmed`.
   - Страницы сайта не запускают миграции и очистку БД. `setup_db.php` доступен только через CLI и вызывает тот же runner.
5. Откройте проект в браузере:
   - `http://localhost/test%20project/`
6. Откройте страницу входа администратора и используйте настроенные переменные окружения:
   - `http://localhost/test%20project/admin/login.php`
7. После входа откройте панель администратора:
   - `http://localhost/test%20project/admin/view_messages.php`

Для работы `.htaccess` Apache должен разрешать `AllowOverride FileInfo`. Если хостинг не поддерживает `.htaccess`, настройте страницу 404 на `/404.php` в конфигурации VirtualHost.

## Примечания

- Проект предназначен для локальной разработки и тестирования.
- В рабочей среде используйте отдельного пользователя БД (не `root`) с непустым паролем и задавайте учетные данные администратора через переменные окружения.
- Не добавляйте `.env` и резервные копии БД в Git; `.env.example` не предназначен для секретов.
- Панель администратора поддерживает фильтрацию, массовое удаление, пометки прочитано/не прочитано и редактирование прямо на странице.
